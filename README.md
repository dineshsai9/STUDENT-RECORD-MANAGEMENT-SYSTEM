My name is T. Dinesh Sai, and this is my project titled
“Student Record Management System (SRMS)”.

This project is developed using C programming language as a console-based application.

The main purpose of this project is to manage student records like
Roll Number, Name, and Marks in a simple and efficient way.

This system uses file handling concepts where:

students.txt is used to store student data

credentials.txt is used for storing user login details

The project includes role-based login system with three users:

Admin – has full access (Add, View, Search, Update, Delete)

Staff – can Add, View, Search, and Update

Guest – can only View and Search student records

This project helped me learn important concepts such as:

File handling in C

Structures and functions

CRUD operations

Role-based access system

Now I am uploading this project source code and documentation to GitHub for sharing and future reference.
